Bionic Hand Power & Sensor PCBs

Multi-board PCB architecture for a 7DOF prosthetic hand under EWB SFU Bionics. Designed schematics and layouts in KiCAD for high-current power distribution, sensor multiplexing, and MCU daughterboards. Performed SMD soldering and hardware-in-the-loop verification.

STM32 Line Follower Robot

Real-time autonomous differential-drive robot built on an STM32 ARM Cortex microcontroller. Engineered bare-metal C register-level peripheral drivers, DMA multi-channel ADC optical array scanning, and real-time digital PID feedback steering control.

Software / Firmware ★ Featured

Bionic Hand HAL Architecture

Designed a modular C/C++ Hardware Abstraction Layer (HAL) for an EMG-controlled prosthetic hand under EWB SFU Bionics. Abstracted low-level I2C/SPI sensor acquisition and PWM tendon actuation from high-level EMG envelope detection and grip state machines.
