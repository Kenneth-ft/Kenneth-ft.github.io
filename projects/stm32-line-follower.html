STM32 Real-Time Line Follower Robot

Autonomous high-speed differential-drive robot engineered with bare-metal C register-level peripheral drivers, DMA multi-channel ADC scanning, and real-time digital PID feedback steering control.

Role Embedded Systems & Controls Developer
Coursework RT/ET Control Systems • SFU
Microcontroller STM32 (ARM Cortex-M)
Key Techniques Register-Level C, DMA, PID, PWM Motor Drives

Project Overview

Developed as the capstone project for Real-Time and Embedded Control Systems at Simon Fraser University, this autonomous mobile robot tracks complex high-speed line trajectories with minimal lateral error. Rather than relying on high-level vendor libraries (like Arduino or standard HAL wrappers), all microcontroller peripheral initialization and timing routines were written in bare-metal C using direct register manipulation.

Bare-Metal Firmware Architecture

  • Register-Level Peripheral Setup: Configured clocks (RCC), general-purpose I/O (GPIO), nested vector interrupt controllers (NVIC), hardware timers (TIM), and analog-to-digital converters (ADC) through direct memory-mapped register writes.
  • DMA Multi-Channel Sampling: Used Direct Memory Access (DMA) to continuously stream 8-channel optical reflectance sensor values into a circular RAM buffer with zero CPU overhead.
  • Deterministic 1 kHz Control Loop: Configured a dedicated hardware timer to fire a high-priority interrupt every 1.0 ms to compute weighted line position and update motor PWM duty cycles.

Digital PID Feedback Control Tuning

The steering control law calculates the robot's error offset \(\epsilon(t)\) from the track center:

  • Proportional Term (\(K_p\)): Generates restoring torque proportional to lateral displacement.
  • Derivative Term (\(K_d\)): Anticipates trajectory inflection and damps overshoot during sharp S-bends using filtered finite differences.
  • Integral Term (\(K_i\)): Eliminates steady-state drift on prolonged banked curves, paired with anti-windup clamping to prevent actuator saturation.

Hardware & Power Electronics

Integrated an optical reflectance sensor bar with dual H-bridge DC motor drivers. Implemented hardware decoupling capacitors and flyback diode protection to isolate motor inductive switching noise from the sensitive 3.3V microcontroller logic rail.
